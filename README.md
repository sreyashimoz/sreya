# Head2Tail

Website for Head2Tail, a veterinary clinic, grooming studio and pet store in Ballygunge, Kolkata.

## Contents

- `head2tail.html` — the full site in a single file. Open it in a browser to view it.
- `images/` — photos used by the site (gallery, about, directors, services).
- `images and videoes/` — original photos and videos from the clinic.
- `Head2tail.txt` — content and design notes for the site.

## Editing director photos

See `images/directors/README.txt`. Open `head2tail.html?edit` to preview photos before saving them.
